# Aetherboard Version 6 Changelog

## New mode

- Added Hardcore Expedition with 40 starting heart and a 25-round victory target.
- Added permanent spirit death after every battle.
- Added immediate defeat when the owned roster is completely wiped.
- Added casualty history and Hardcore records.

## Pre-run strategy

- Added a ban phase for one role and two individual spirits.
- Added a 15-spirit Faction Deck builder.
- Added a generated five-spirit Global Pool.
- Restricted Hardcore draft and shop rolls to the selected deck and global pool.

## Active combat

- Added Localized Freeze.
- Added Rally Pulse.
- Added temporary Terrain Walls with pathfinding avoidance.
- Added Focus Banners for forced target priority.
- Added shared cooldown, targeting UI, keyboard shortcuts, and online action relay.

## Arenas and environment

- Added six rotating arena maps.
- Added lava, brush, ice, mana currents, blocked cells, missing floor, and choke points.
- Added rotating weather every five rounds.
- Added Speed, Ward, and Mana positional nodes.
- Added map/environment explanations to the Run panel.

## Black Market

- Added a health-priced Black Market every fifth Hardcore round.
- Added corrupted items and corrupted unit recruitment.
- Added Soul Stitch resurrection, Forbidden Promotion, and Blood Contract.
- Added Grave Idol permanent-death protection.

## Interface

- Added Hardcore title-screen selection.
- Added visible map/weather information.
- Added a combat commander-action bar.
- Updated the tutorial and keyboard guide.
- Preserved blue ally and red enemy identification.
- Preserved strongest-source, non-stacking stat presentation.

## Multiplayer server

- Added validated `combat-action` messages.
- Added deterministic environment seeds to battle payloads.
- Added reconnect-safe combat action logs.
- Preserved Duel, Party, reconnect, and authority-reassignment behavior.

## Balance retained

- Vanguard tiers remain +8, +18, and +30 armour at 2, 4, and 6 units.
- Same-stat bonuses continue using only the strongest source.
